Compare Futures: AI News — Architecture (draft for owner approval)

Branch claude/compare-futures · DeepSeek Search every 3 hours → rule checks → up to 25 items per study field → For you / Explore all

Usable result (N4, N5)

  • • Has a title
  • • http or https link with a host
  • • Publish date present, not in the future, within 30 days
  • • Repeats removed (same link or same headline)
  • • Merged with the kept list, newest first, top 25 per field

Refresh and cost (N1, N6)

  • • 10 searches per run, every 3 hours
  • • Hard caps: 10 per run, 80 per 24 hours
  • • US$0.75 per 1,000 searches → about US$1.80 a month
  • • Failed / empty searches not charged
  • • Owner gives the key and the OK before the first real search

Boundaries

  • • No profile data to the server or DeepSeek
  • • Key in server secrets only; never in logs or replies
  • • Only title, link, site, date, snippet kept; no article text
  • • DeepSeek text shown as plain text
  • • English news only; scenario table not in this spec (N8)
