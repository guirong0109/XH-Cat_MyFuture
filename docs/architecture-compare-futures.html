Compare Futures: AI News — Architecture (Amendment 1, draft for owner approval)

Branch claude/compare-futures · DeepSeek Search every 3 hours → rule checks → DeepSeek relevance check (N9) → up to 25 English items per study field → For you / Explore all

Usable result (N4, N5, N10)

  • • English articles only (lang:en), said on screen
  • • Has a title and an http or https link
  • • Publish date present, not in the future, within 30 days
  • • Repeats removed: same link, or same headline without a trailing site name
  • • Merged with the kept list, newest first, top 25 per field

Relevance check (N9)

  • • deepseek-flash, thinking off, JSON answer, max 1000 tokens
  • • New items only; one request per field per run
  • • Kept only if listed in "keep"; everything else dropped
  • • Blank or wrong answer: one retry, then no new items for that field
  • • Sends only headline, site, snippet and field title

Refresh and cost (N1, N6, N9)

  • • 10 searches + 10 checks per run, every 3 hours
  • • Hard caps for each: 10 per run, 80 per 24 hours
  • • Search US$0.75 per 1,000 → about US$1.80 a month
  • • Check about US$2–4 a month, ceiling about US$6.50
  • • Counts kept in memory and in the store, before each request

Boundaries

  • • No profile data to the server or DeepSeek
  • • Key in server secrets only; never in logs or replies
  • • Unchecked items never shown; no article text kept
  • • DeepSeek text shown as plain text
  • • Career Matching still uses no language model
