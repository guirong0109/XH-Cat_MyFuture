Career Matching — Architecture (draft for owner approval)

Branch claude/career-matching · official code chain → levels met ÷ needed → outlook bands per AI scenario → SDG team-draft links (shown now, M16)

One user's path

  • • Confirmed profile (CV or form) is sent with the request
  • • chain.js finds each eMASCO role's O*NET jobs, or the missing step
  • • fit.js: levels met ÷ levels needed, best O*NET job shown
  • • outlook.js puts each role in one of 4 bands per scenario
  • • Card: %, why (chart), what raises it, outlook, SDG tags
  • • Choose this role → SDG contribution of the path

Guards that keep it honest

  • • No method from the old project; every weight is O*NET's
  • • No AI or word linking: official code chain only
  • • Trends and scenarios never change the Skill Match
  • • Group-level job ads labelled "not this job"
  • • Every SDG team-draft link appears (M16); rejected ones are hidden
  • • Missing data says "not available", never a guess
