Study Pathway — Architecture (draft for owner approval)

Branch claude/study-pathway · matching's role answer → skills to build + study route → named team picks and links out

One user's path

  • • In #match, "Plan my study pathway" saves the role as a target
  • • /api/pathway asks matching for the role's rows (same numbers)
  • • steps.js: gaps biggest first, then "not assessed yet", then met
  • • route.js: usual education level and fields of study (official tables)
  • • Named team picks from many sites under each field and skill
  • • "More on Coursera / edX / e-LATiH / …" opens each site's own search
  • • Click → the course or programme page opens on its own site
  • • Mark started / done; saved on the device, per skill

Guards that keep it honest

  • • No method from the old project; order is matching's own gap points
  • • Only name + link + date stored from any site (none is open data)
  • • No invented links: every site and pick opened in a browser first
  • • Every pick labelled team draft or "approved by owner on date"
  • • NEC ↔ ISCED-F labelled "code match, not an official table"
  • • "Done" never changes the Skill Match; no language model
  • • Missing data says so, never a guess
